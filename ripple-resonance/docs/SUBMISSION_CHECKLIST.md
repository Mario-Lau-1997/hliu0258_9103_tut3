# Submission preparation

## What is already in this project

- A functional local p5.js prototype with a bundled, pinned library.
- Descriptive modules, classes, comments and a responsive layout.
- An English README with inspiration, techniques, mechanic ownership,
  AI acknowledgement, external references and interaction instructions.
- A Chinese quick guide.
- Mathematical tests and automated browser test evidence.
- Real Git commits attributed to the AI assistant, with their actual dates.

## What you must personalise and complete

1. Add your name and student ID where your course requires them. The README
   currently identifies the owner as the sole student, not a named team.
2. Read the README and explain `sample`, `contourSegments`, `gradientAt` and
   the input controller in your own words. The longer Chinese guide can help.
3. Run the artwork on the laptop you will use. Check its projector contrast
   and try the controls yourself.
4. Keep the AI acknowledgement. The existing commits are honestly labelled
   as AI-assisted development; they are not evidence of your independent work.
5. Make and commit your own meaningful changes and record your actual tests.
   The brief requires at least three meaningful commits per student excluding
   initial setup. A real visual adjustment, a tested behaviour improvement,
   and a documented test/fix are examples if you actually do that work.
6. Create or choose your own GitHub repository. Upload the full source and
   preserve the Git history if using the included bundle.
7. Open the uploaded repository and check the README, paths, library licence
   and all JavaScript files. Submit the repository link required by Canvas.

There is no remote repository URL in this package because no GitHub account
or target repository was supplied. No remote upload has been performed.

## Restore the included Git history

From the extracted **package** folder, which contains `git-history.bundle`, run:

```bash
git clone git-history.bundle Ripple-Resonance
```

This creates a normal local repository. Open it in GitHub Desktop, review the
history, make your actual changes, and publish it to your own chosen repository.
Alternatively, connect it to an empty repository using Git. Use the real URL
from your own GitHub account; none is invented here.

Uploading loose files through GitHub's web page will not preserve the bundle's
earlier history. Do not change commit author names to make AI commits appear
to be independent student contributions.

## Demonstration sequence

1. Restore the two-source scene.
2. Pause time so that a visual change can be compared at one moment.
3. Drag one source closer to the other and point out the changing bands.
4. Reverse the selected phase and compare the new pattern.
5. Resume time and show how the particles follow the changed field.
6. Change drift briefly, then explain that noise supports the main interaction.

This sequence uses working behaviour. Do not describe it as a completed
classmate user study or as a full physical simulation of water.
