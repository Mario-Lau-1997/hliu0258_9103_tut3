# Ripple Resonance 中文快速说明

这是之前Ripple提案的可运行升级版。主机制仍是用户输入。观众通过添加、拖动和反转波源，改变所有波源共同形成的图案。Perlin noise和带种子的随机数支持粒子的自然变化。

## 怎样打开

完整解压项目，打开`index.html`。不要只取出HTML文件，`js`和`vendor`文件夹需要一起保留。p5.js已放在项目内，作品运行不需要联网、npm、麦克风或音频文件。已在阻断外网请求的Chrome无头浏览器中验证本地打开。

## 怎样操作

| 操作 | 结果 |
| --- | --- |
| 点击画布空处 | 添加一个持续存在的波源，最多6个 |
| 拖动带数字的波源 | 改变它的位置，也改变整个场的叠加图案 |
| Reverse phase或P | 反转选中波源的相位，改变增强与抵消的位置 |
| Source strength | 改变选中波源的强度 |
| Wave spacing | 调整所有波源的波纹间距 |
| Natural drift | 调整Perlin流场对粒子路径的影响 |
| Pause或空格 | 暂停时间，仍能拖动、改相位和调参数 |
| Remove或Delete | 删除选中的波源 |
| Restore scene或R | 恢复初始波源、时间、间距、漂移和种子 |
| New drift或N | 更换种子，重新生成粒子的起点与漂移 |
| Save image或S | 导出程序当前画布的PNG |
| G | 隐藏或显示波源数字标记 |
| 画布获得焦点后按方向键 | 移动选中的波源，按住Shift可以更快移动 |

按钮、滑块获得焦点时，字母快捷键不会运行。先点击画布再使用快捷键。手机采用单指拖动，不支持同时编辑多个触点。

## 为什么比原方案深入

原来每个圆环独立绘制，主要变化是半径和淡出。现在每个波源都在同一个二维场内贡献数值，所以移动一个波源会改变它与其他波源的关系。线条和粒子同时读取这个共享场，因此变化具有一致的原因。

青绿与珊瑚色代表合成波值的正负，不代表两个人。波源旁边的加减号表示相位。作品借用了波的叠加思路，但不是完整的水体物理模拟，也没有多人联网功能。

## 先理解这四件事

1. **叠加**：在同一个位置，把所有波源给出的数值相加。
2. **相位**：反相会让某个波源的数值变号。完全重合、等强度、反相的两个源会抵消。
3. **等值线**：在网格里寻找相同波值的位置，把边上的交点连成线。
4. **粒子运动**：粒子沿场的等值方向移动，再加入较小的平滑噪声方向。轨迹缓慢淡出，留下短暂的运动记忆。
