# Development stages

The common painted background is applied to every snapshot in this refreshed set.

## Stage 1: Source controls

Add sources with a button or the A key; choose overlapping sources from a list. Match pointer IDs when ending a drag.

## Stage 2: Undo and redo

Capture small scene snapshots. Group continuous gestures into one edit. Restore settings, clear redo after a new edit, and cap the stack at 30.

## Stage 3: Scene files

Save editable scene settings as JSON. Check file size, format, version, numeric limits and source IDs before applying a scene. Include reinforcement and cancellation examples.

### Final audio update

Add a local audio track, interaction drops and a separate audio mechanic module.
Measure the output level and pass a limited strength multiplier to the wave field.
Start only after the listener enables sound. Connect playback to pause, scene load
and tab visibility. Keep audio session settings separate from editable scene data.

The snapshots do not change the author or dates of any existing Git commits.
