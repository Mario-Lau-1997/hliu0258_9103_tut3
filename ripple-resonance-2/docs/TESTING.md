# Development checks

The included reports record automated local checks. They do not claim testing by
any named student or classroom participant. `unit-results.tap` contains the logic
checks. `browser-results.json` contains the stage-specific UI checks.
`background-results.json` records image loading, resizing and PNG export checks.

Run the tests as explained in README.md. An actual test log should record the
software version, device, procedure, result and any follow-up fix.
