# Supplied background image

The user supplied this water-reflection painting for the project. The image bytes
in `water-reflections.png` are unchanged. Its artist, title and original publication
URL were not supplied, so no attribution to a named artist is invented.

`background-image.js` contains the same image bytes as a data URL for offline
loading and canvas export. The program draws moving contours and particles above
the fixed painting. The p5.js library and its licence are in `vendor/`.
